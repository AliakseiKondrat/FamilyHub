# Telegram: как включить бота и мини-приложение

Код готов и выложен (функция `telegram` в Supabase). Пока нет токена бота, она отвечает «not configured».
Создать бота и вставить токен может только владелец аккаунта: токен — это секрет, его нельзя передавать
ни помощникам, ни в чат.

## 1. Создать бота (2 минуты, в Telegram)
1. Открыть **@BotFather** → `/newbot`.
2. Имя: `Family Hub` (или своё). Юзернейм: любой свободный, например `familyhub_couple_bot`.
3. BotFather пришлёт **токен** (`123456:ABC…`). Никому его не пересылать.

## 2. Положить токен в Supabase (1 минута)
1. supabase.com → проект **bczhzciusnpjtxlznrse** → **Edge Functions** → **Secrets**.
2. Добавить секрет: имя `TELEGRAM_BOT_TOKEN`, значение — токен из BotFather. Сохранить.

## 3. Подключить (одна кнопка, в приложении)
1. В Family Hub: **Настройки → Режим разработчика → Telegram → «Подключить бота»**.
2. Приложение само пропишет вебхук (с секретным заголовком) и кнопку меню «Family Hub» у бота.
3. Появится сообщение «Бот @… подключён».

## Что умеет
- Кнопка меню и `/start` открывают Family Hub внутри Telegram (та же PWA: тема, кнопка «назад», вибро).
- **Вход:** кто уже с аккаунтом — входит по почте, как раньше; новые могут нажать «Войти через Telegram».
  Если открыть мини-приложение, будучи вошедшим по почте, бот запоминает, кто это.
- **Ссылки и заметки боту:** пришли ссылку или текст → бот спросит «Куда сохранить?» →
  Входящие / Задачи / Продукты / Смотреть / Рецепты / Вишлист / Места. Запись сразу появится у обоих.
- Уведомления пока приходят как веб-пуши PWA (бот их не дублирует).

## Как это устроено
- Функция `supabase/functions/telegram/index.ts`: проверка `initData` по алгоритму Telegram (HMAC-SHA256),
  вход через одноразовый токен magic-link, вебхук с секретным заголовком, выбор раздела через inline-кнопки.
- Таблицы `tg_links` (Telegram id ↔ почта, чат) и `tg_pending` (ссылки, ждущие выбора раздела) —
  доступ только у серверной функции (RLS без политик).
- Клиент: `src/lib/telegram.ts` — скрипт Telegram грузится только внутри Telegram.
