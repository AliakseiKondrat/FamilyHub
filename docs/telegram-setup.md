# Telegram: бот, мини-приложение, уведомления

**Состояние на 7 ноября 2026:** бот **@fh_pwa_link_bot** создан и подключён.
- Токен лежит в секретах Supabase (`TELEGRAM_BOT_TOKEN`).
- Вебхук и кнопка меню «Family Hub» прописаны.
- Функции: `telegram` v6, `push` v7.

Токен — секрет. Его нельзя передавать ни помощникам, ни в чат. Если токен где-то засветился, его перевыпускают в @BotFather (`/revoke`), кладут новый в секреты и снова жмут «Подключить бота».

## Если бота нужно подключить заново (новый бот или новый токен)
1. **@BotFather:**
   - для нового бота: `/newbot`, взять токен;
   - для старого бота: `/revoke`, взять новый токен.
2. **Supabase** (supabase.com → проект **bczhzciusnpjtxlznrse**):
   - Edge Functions → Secrets → `TELEGRAM_BOT_TOKEN` = токен;
   - сохранить.
3. **Family Hub:**
   - Настройки → Режим разработчика → Telegram → «Подключить бота»;
   - приложение пропишет вебхук (с секретным заголовком) и кнопку меню.

## Здоровье бота (панель разработчика)
Блок «Telegram» в режиме разработчика показывает:
- имя бота;
- адрес вебхука;
- последнюю ошибку доставки и число ожидающих обновлений;
- сколько людей привязано.

Кнопка «Подключить бота» там же переустанавливает вебхук.

## Что умеет

### Мини-приложение
Кнопка меню и `/start` открывают Family Hub внутри Telegram. Это та же PWA: тема, кнопка «назад», вибро.

### Вход
- Кто уже с аккаунтом — входит по почте, как раньше.
- Новые могут нажать «Войти через Telegram».

### Привязка Telegram к существующему аккаунту
Два способа:
- **Из мини-приложения.** Если открыть Family Hub внутри Telegram, будучи вошедшим по почте, бот запоминает, кто это. Так привязан Лёша.
- **Из PWA.** Настройки → Уведомления → «Привязать Telegram».
  1. Приложение получает одноразовый код (таблица `tg_codes`).
  2. Открывается `t.me/fh_pwa_link_bot?start=<код>`.
  3. В боте нужно нажать «Запустить».
  4. Бот связывает Telegram-аккаунт с почтой и чатом (`tg_links`).

  Отвязать: там же, «Отвязать Telegram».

### Куда присылать уведомления
Выбирает каждый для себя: Настройки → Уведомления → «Куда присылать».
- **Приложение** — веб-пуш PWA.
- **Telegram** — сообщение от бота с кнопкой «Открыть Family Hub».
- **Оба** — и то и другое.

Если выбран Telegram, а бот сообщение доставить не смог (не привязан, бот заблокирован), уведомление уходит пушем, чтобы не потеряться. Кнопка «Проверить в Telegram» шлёт тестовое сообщение через выбранный канал.

### Ссылки и заметки боту
1. Пришли ссылку или текст.
2. Бот спросит «Куда сохранить?»: Входящие / Задачи / Продукты / Смотреть / Рецепты / Вишлист / Места.
3. Запись сразу появится у обоих.

Бот сам угадывает раздел по ссылке и ставит его первой кнопкой со ⭐:
- карты → Места;
- стриминги и YouTube → Смотреть;
- сайты рецептов → Рецепты;
- магазины → Вишлист.

Магазины — польские (Allegro, OLX, Empik, x-kom, Vinted, Zalando, Ceneo, IKEA…) и испанские (Wallapop, El Corte Inglés…). Российские убраны.

## Как это устроено
- **Функция `supabase/functions/telegram/index.ts`:**
  - проверка `initData` по алгоритму Telegram (HMAC-SHA256);
  - вход через одноразовый токен magic-link;
  - коды привязки (`linkCode`), `status`, `unlink`;
  - `diag` и `setup` — только для разработчика;
  - вебхук с секретным заголовком: `/start <код>`, выбор раздела inline-кнопками.
- **Функция `supabase/functions/push/index.ts`:**
  - `sendTo(дом, роль, сообщение)` смотрит выбранный канал (`notify.channel`: `push` / `tg` / `both`);
  - шлёт в Telegram и/или веб-пушем;
  - если Telegram не дошёл — отправляет пушем.
- **Таблицы** — доступ только у серверных функций (RLS без политик):
  - `tg_links`: Telegram id ↔ почта, чат;
  - `tg_pending`: ссылки, ждущие выбора раздела;
  - `tg_codes`: одноразовые коды привязки.
- **Клиент:** `src/lib/telegram.ts` — скрипт Telegram грузится только внутри Telegram.

## Ещё не проверено вживую
Тест на живом сообщении отложен (Лёша: «Позже»):
1. Отправить боту ссылку (например, с Allegro).
2. Нажать ⭐.
3. Убедиться, что запись появилась у обоих.
4. Получить обычное (не тестовое) уведомление через бота.
