## 1. Коротко
Ottership — Telegram-мини-приложение для пары (≈49,5 тыс. пользователей в месяц), коричнево-кремовое, «уютное», с выдрой-питомцем.
Сила — в **эмоциональных механиках вокруг пары**: питомец с огоньком, записки-сюрпризы, свидание вслепую, еженедельный чек-ин,
бот, который пишет второму партнёру («julia сейчас грустит — может, обнять?»). Бытовая часть (покупки, дела, рецепты, поездки, календарь)
у них проще и местами слабее нашей. Деньги — косметика за Telegram Stars (темы, фоны, открытки), общая на пару, покупка навсегда.

FamilyHub сильнее в быте и организации (Google-календарь/задачи, бюджет с долгами, цикл, фото, музыка, глубокие настройки, импорт рецептов,
картинки по ссылкам реально работают). Слабее — во всём, что создаёт **ощущение «мы вместе»** и **поводы открыть приложение каждый день**.

## 2. Вход и онбординг
1. Поиск @Ottership_bot → описание бота → «Запустить бота» → приветствие с кнопкой «💞 Открыть Ottership».
2. Telegram просит принять условия мини-приложений (один раз).
3. **Гейт подписки на канал** — без подписки дальше не пускают («Подписаться на канал» / «Я подписался — проверить»). Так они растят канал (≈39,5 тыс.).
4. Экран «Ваше маленькое пространство для двоих»: выбор **Пара / Друзья**, «Создать наше пространство», «У меня есть приглашение».
5. Сразу «Ваше пространство готово»: код из 6 символов и кнопка «Пригласить партнёра» = нативное «Переслать» Telegram с готовой ссылкой
   `t.me/Ottership_bot?start=join_КОД`. Пока ждёшь — «Добавь первое место», экран обновится сам.
6. Партнёр жмёт ссылку → бот «💞 Тебя пригласили…» → «Присоединиться» → **«Кто ты? Парень / Девушка / Не указывать»** (для правильного рода в текстах).
7. Тур из 5 слайдов (места и жребий, быт, сюрпризы, питомец) и чек-лист «Первые шаги 0/5».
8. Аккаунт, аватары и имена берутся из Telegram — никаких паролей и писем.

**Вывод для нас:** вход через Telegram + приглашение одной ссылкой — то, чего у нас нет и что нужно для публичной версии (сейчас у нас пары заводятся вручную в базе).

## 4. Неочевидная логика
- **Синхронизация не мгновенная.** Почти всё у партнёра обновляется только после перезагрузки (меню ⋮ Telegram или потянуть вниз на главной).
  Мгновенно — только экран ожидания пары и счётчик «тапов вдвоём». Отмеченный хлеб у партнёра не пропал даже через 10 с.
  При этом в настройках написано «синхронизировано в реальном времени». У нас realtime через Supabase — это наше преимущество.
- **Бот — главный канал уведомлений** и «эмоциональный усилитель»: пишет о добавленном месте, назначенном деле, 30 тапах партнёра,
  «julia грустит», «julia ждёт твой сюрприз», «оба ответили на чек-ин». О покупке подарка/копилке/фильмах — молчит (чтобы не спалить сюрприз и не спамить).
- **Засеянные примеры** («🌱 … (пример — можно удалить)») в каждом разделе, раздаются партнёрам поровну — пустых экранов почти нет.
- **Род по полу** везде («ответила / выполнил»), но в заданиях дня всё равно «он(а)».
- Почта/телефон не нужны — Telegram-профиль; «онлайн»-точка у аватара партнёра.
- Монетизация: Telegram Stars или крипта через @CryptoBot ($2,49 ≈ 150 ⭐); покупка одна на пару, навсегда.
- Баги: текст приглашения после ссылки; ошибка сервера при запечатывании свидания (вторая попытка прошла); при отправке записки
  клавиатура перекрывает лист, Back закрывает лист с потерей текста; форма дела сбрасывает выбор при прокрутке;
  картинки по ссылке не подтянулись ни с Amazon, ни с сайта Łazienki (только YouTube через бота).

**Форма:** крупные скругления (карточки ≈24 px, листы ≈32 px сверху, кнопки-таблетки), мягкие тени, много воздуха.
Нижнее меню — белая «плавающая» панель с круглой коричневой кнопкой «Мы» по центру (выступает над панелью).
Заголовки — жирный геометрический гротеск; подписи разделов — капслок мелким серым. Иллюстрации — стикеры-выдры, 3D-эмодзи-свинка.

**Анимации** (замер по записи, 60 fps):
- Переключение вкладок ≈ 0,2 с: мелькает «скелет», затем контент проявляется с лёгким сдвигом вверх.
- Лист снизу открывается ≈ 0,25 с (выезжает и проявляется, фон затемняется), закрывается ≈ 0,2 с.
- Тап по питомцу — облако сердечек ≈ 2 с; 30 тапов — колпак и конфетти; задание дня — галочка, «+5 XP», тост с огоньком.
- Жребий: «Крутим колесо…» → колесо секторами → «ЕСТЬ!» → карточка места (≈ 4–5 с в сумме).
- Копилка: монетка падает в свинку, свинка «удивляется»; тост «Пополнено: +200$ · Отменить».
- Примерка темы: падающие листья, гирлянда на карточке пары, тёмная плашка с таймером 60 с.

## 6. Что предлагаю перенести (по ценности)
1. **Ежедневный ритуал пары**: «Как ты сегодня?» + задания дня + огонёк (без платных скинов). Уведомление партнёру при «грустно».
2. **Записка-сюрприз** с отложенной/случайной доставкой (у нас есть пуши — придёт как уведомление).
3. **Чек-ин недели** (6 вопросов, результат после ответа обоих).
4. **Свидание вслепую** — мастер поверх нашего surprise-режима: настроение, место, время раскрытия, подсказки по расписанию.
5. **Места**: колесо-жребий, звёзды и «вернёмся», спонтанное/запланированное.
6. Вишлист: статус «вручено» → «Мне подарили»; **«Идеальный вечер»** (фильм + рецепт).
7. Блок **«Что видит партнёр»** в настройках, FAQ, тихие часы, «раз в N месяцев + напомнить за N дней» для дел.
8. Засеянные примеры вместо пустых экранов для новых пар.
9. Для публичной версии: **Telegram-мини-приложение + бот** как вход для новых пар (одна ссылка-приглашение), PWA — для виджетов и Siri.

Не брать: гейт подписки на канал, платные темы с примеркой, «тапы любви» как отдельную механику (спорно — обсудить).

## 7. Что можно посоветовать владельцу Ottership
- Включить настоящий realtime (сейчас нужен ручной reload, хотя UI обещает «в реальном времени»).
- Чинить формы: клавиатура и Back на Android теряют введённый текст; сброс полей при прокрутке.
- Превью ссылок: Amazon/обычные сайты не дают картинку — нужен серверный парсер og:image / JSON-LD.
- Текст приглашения: подпись перед ссылкой; «он(а)» в заданиях при известном поле.
- Планшетная раскладка.

## 8. Для Threads-дневника
- Цепляет тон: всё про «вас двоих», маленькие ритуалы и сюрпризы, бот как третий участник, который «подталкивает» к заботе.
- Подача: милая выдра, пустых экранов нет, первые шаги с галочками, «примерь бесплатно».
- Наш угол: «не только мило, но и полезно» — бюджет, календарь, быт, цикл, и всё это синхронно в реальном времени.
