## Как опубликовать пост
- Функция `telegram`, запрос `{ type: 'post', text, pin?, button? }` с токеном разработчика.
  - `text` — HTML-разметка Telegram: `<b>`, `<i>`, `<a href="…">слова</a>`.
  - Ссылки прячем под слова, а не вставляем голыми адресами.
- Запускать из открытого приложения на телефоне разработчика (токен сессии берётся там) — так делали 8 ноября.
- Публиковать только после «да» Лёши на точный текст.
